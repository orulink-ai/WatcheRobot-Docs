# 固件版本管理

切换固件版本、恢复出厂设置和修复无法启动的设备，解决的是不同问题。选择操作前，请先确认你的目标。

## 在客户端切换版本

需要升级或降级时，请使用客户端提供的版本管理功能。客户端会显示当前设备可以安装的版本；没有出现在列表中的版本，可能不适用于你的设备。

切换版本前：

- 保持设备稳定供电；
- 不要在下载或安装过程中断开连接；
- 如果客户端提示需要清除数据，请先备份需要保留的内容。

## 恢复出厂设置

恢复出厂设置适合以下情况：

- 需要更换 Wi-Fi 或重新配置设备；
- 设备设置异常，希望从默认设置重新开始；
- 准备将设备交给其他人使用。

::: warning 固件版本不会改变
恢复出厂设置只会重置设备数据，不会把设备降级到购买时的版本，也不会安装其他固件。重启后，设备仍然运行操作前的固件版本。
:::

恢复出厂设置会清除：

- 已保存的 Wi-Fi 信息；
- 设备设置和本机保存的凭据；
- 已下载到设备中的 Application。

设备不会主动删除 SD 卡中的文件。如果你准备转让设备，请取出 SD 卡，或自行确认其中没有需要删除的个人内容。

### 操作前

- 记录稍后需要重新连接的 Wi-Fi 名称和密码；
- 确认需要保留的内容已经备份；
- 保持设备电量充足或连接电源。

### 操作步骤

1. 在设备上打开 **Settings**。
2. 进入 **Factory Reset**。
3. 按照屏幕提示滑动确认。
4. 等待设备自动重启。重启完成前不要关闭电源。

### 操作完成后

设备会回到等待配置的状态。请重新连接 Wi-Fi、在客户端中连接设备，并按需重新下载 Application 和调整设备设置。

## 更新失败时

恢复出厂设置不能修复损坏的固件，也不能用于选择另一个固件版本。

如果设备在更新后无法正常启动，设备可能会通过 OTA 自动回滚返回上一个可用版本。如果设备没有自行恢复，或已经无法进入设置页面，请使用 USB 有线救援。

## 有线救援

当设备无法正常启动，或客户端无法连接设备时，请使用 USB 和官方救援包进行恢复。除非官方操作说明明确要求，否则不要执行整机擦除。

## 选择正确的操作

| 你的目标 | 使用的功能 | 固件版本是否改变 |
| --- | --- | --- |
| 升级或降级 | 客户端版本管理 | 是 |
| 清除设置并重新配置设备 | 恢复出厂设置 | 否 |
| 更新后无法启动 | OTA 自动回滚或 USB 有线救援 | 视恢复方式而定 |
| 设备完全无法正常启动 | USB 有线救援 | 由所选官方救援包决定 |
